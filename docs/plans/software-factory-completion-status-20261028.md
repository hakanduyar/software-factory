## Governance reconciliation

Historical plan wording imposing artificial author output, token, turn, structured-report size or total-duration ceilings has been superseded by explicit human directions. Admission expiry applies before launch, not as an executing author-job kill. Manual cancellation, intrinsic provider/backend limits, connection/lock/network timeouts, post-stop cleanup, security, PaidOFF, single-writer ownership and independent review remain. The fallback automation interval is now 60 minutes by explicit human instruction, not the original plan's 20 minutes. The resumed-period weekly-reservation exception is temporary. Exact current human direction and per-task admission remain authoritative; this status document cannot renew them.
